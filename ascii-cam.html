ASCII Cam

Turns any video, image, or your webcam into live ASCII art, in the same glyph style as the scenes on my homepage. Nothing is uploaded: every frame is converted inside this tab.

    How It Works

    The homepage scenes are drawn by hand, cell by cell. ASCII Cam does the same thing from real pixels. Each frame of the source is drawn small onto an offscreen canvas, one pixel per character cell, and each pixel's brightness picks a glyph.

    • Downsample: the frame is drawn at the grid size (for example 120×45). Rows are about half as many as columns because a monospace cell is roughly 0.6 as wide as it is tall.
    • Luminance: each cell becomes 0.2126r + 0.7152g + 0.0722b.
    • Auto-levels: the 2nd and 98th brightness percentiles are stretched to the full ramp and eased over time, so a dim webcam still uses every glyph without flickering.
    • Ramp + tone: brightness indexes into the glyph ramp and also picks one of four colors (faint, muted, foreground, accent), the same tones the homepage scenes use.

    In light mode the mapping flips automatically, so dense glyphs always stand for the parts of the picture that would be ink.

    Edges Mode

    Edges mode runs a Sobel filter over the brightness grid. Where the gradient is strong, the cell becomes a line glyph (- / | \) that follows the edge's direction, corrected for the tall cell shape. Everything else falls back to a dim brightness fill. The result looks closer to the hand-drawn scenes than a plain brightness ramp.

    Recording

    Recording redraws every ASCII frame onto a canvas in the current theme's colors, captures it with canvas.captureStream(), and encodes it with MediaRecorder. Chrome and Firefox save .webm; Safari saves .mp4. When the source is a video file in Chrome, its audio is mixed into the recording. A file recording stops on its own when the clip ends.

    Privacy

    There is no server. Files are read through a local object URL, the webcam stream is only ever drawn to a canvas, and recordings are assembled in memory and handed straight back to you as a download. Close the tab and it's gone.
